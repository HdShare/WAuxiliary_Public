## 通知:

经过慎重考虑，我们不得不遗憾地宣布，由于不可抗拒力因素，即日起将停止 WAuxiliary 项目的所有维护和更新工作。

感谢多年来大家对 WAuxiliary 的喜爱与支持。我们深知，正是因为有了用户的支持，WAuxiliary 才得以走到今天。

在 WAuxiliary 的开发历程中，我们有幸能在 WAuxiliary 讨论群组中与许多优秀用户进行交流，并收获了许多宝贵建议。

路再长也有终点，夜再长也有尽头。江湖路远，后会有期。我们衷心的祝愿大家能在未来的生活中找到属于自己的幸福。
